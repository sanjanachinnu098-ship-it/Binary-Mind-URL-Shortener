🔗 Binary Mind – URL Shortener

📌 About the Project

Binary Mind is a web application that converts long URLs into short and easy-to-share links.

🎯 Objectives

- Generate short URLs.
- Redirect users to original websites.
- Make sharing links easier.
- Track link clicks.

✨ Features

1. URL Shortening
2. Short URL Redirection
3. Copy Link
4. Click Counter

💻 Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

⚙️ How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Run "npm install".
4. Run "npm start".
5. Open "http://localhost:3000" in your browser.
